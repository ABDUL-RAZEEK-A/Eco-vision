EcoVision - Real-Time Waste Detection & Classification System
Project Documentation & Details
================================================================================

1. OBJECTIVES (ONLY TWO)
--------------------------------------------------------------------------------
Objective 1: To develop an intelligent, real-time computer vision system using an ensemble of YOLOv8 models to automatically detect and classify municipal solid waste into degradable (organic/biological) and non-degradable (plastic/e-waste/metal) categories.

Objective 2: To create a responsive, web-based interface that processes camera feeds and visualizes detection results, providing immediate feedback and analytics (bio vs. non-bio counts) to encourage proper waste segregation and recycling.


2. METHODOLOGY
--------------------------------------------------------------------------------
- Data Collection & Preprocessing: Gathering images of various waste items (e.g., banana, cardboard, bottle, e-waste). Preprocessing and annotating them into format suitable for YOLO object detection training.
- Model Selection & Architecture: Utilizing an ensemble of YOLOv8 (You Only Look Once version 8) nano and custom-trained models to achieve an optimal balance between high-speed real-time inference and high accuracy.
- Backend Development (Flask): Implementing a Python Flask backend to handle asynchronous POST requests containing base64 encoded image frames from the client's webcam.
- Inference & Post-processing: Passing frames through the YOLOv8 models, extracting bounding boxes, confidence scores, and class labels. Applying PyTorch-based Non-Maximum Suppression (NMS) to eliminate duplicate bounding boxes across the different models and mapping predicted classes to parent categories ("degradable" and "non_degradable").
- Frontend Visualization: Using JavaScript and HTML5 Canvas on the client side to render the normalized bounding boxes smoothly over the video feed, alongside dynamic live counters for biological and non-biological waste objects.

5. EXPERIMENTAL RESULTS
--------------------------------------------------------------------------------
- The ensemble YOLOv8 approach successfully detects and classifies waste objects in real-time under varying lighting conditions with high confidence scores (typically > 65%).
- The system accurately categorizes 70+ specific item types (e.g., paper_cups, aluminum_soda_cans, organic) into their correct parent buckets: Degradable vs. Non-Degradable.
- The implementation of an IoU threshold of 0.5 in the NMS algorithm successfully handles overlapping items, ensuring objects are not double-counted by the overlapping models.
- Web interface latency is kept to a minimum by utilizing base64 frame transmission and client-side canvas rendering. By offloading bounding-box rendering to the browser rather than OpenCV on the server, the video stream remains smooth and responsive.

8. INNOVATION ADDED IN THE PROJECT
--------------------------------------------------------------------------------
- Ensemble Model Inference: Instead of relying on a single detection model, the project innovatively runs inferences across four distinct YOLOv8 models concurrently. This maximizes detection coverage across a vast array of custom biological and non-biological classes that a single model might miss.
- Class-Agnostic Non-Maximum Suppression (NMS): Implemented custom PyTorch NMS logic over the combined results of all four models. This seamlessly merges predictions and prevents multiple bounding boxes from different models being drawn over the same physical object.
- Normalized Client-Side Rendering: The backend innovatively avoids spending computational resources drawing bounding boxes onto images via OpenCV. Instead, it returns normalized geometric coordinates (0.0 to 1.0), allowing the JavaScript frontend to render smooth, responsive overlays that scale perfectly to any screen or canvas size.
- Dynamic Waste Mapping System: Features an exhaustive dictionary mapping both standard COCO classes and custom-trained classes into binary environmental categories, effortlessly simplifying complex multi-class object detection into actionable environmental metrics for the end-user.
